# 面向离散制造业产品BOM智能解析与物料替代方案推理B/S系统 —— 需求规格说明书

版本 1.0

## 1 引言

### 1.1 编写目的
本文档定义系统的功能需求、非功能需求与接口约定，作为开发、测试与验收的依据。

### 1.2 项目背景
离散制造企业的产品 BOM（物料清单）维护中，物料停产（EOL）、缺货、采购交期超期频繁发生。
传统做法依赖 BOM 工程师人工查找替代物料：耗时长、对比维度少（往往只比价格），容易忽略
性能与工艺兼容约束，替代方案可靠性差。本系统利用制造智能技术自动解析 BOM、识别风险物料、
推理候选替代物料、多维度评估替代方案，辅助工程师快速完成物料替换决策。

### 1.3 术语定义
| 术语 | 说明 |
|---|---|
| BOM | Bill of Materials，物料清单（父件-子件-用量层级结构） |
| EOL | End of Life，物料停产 |
| 风险物料 | 缺货、停产、即将停产、交期超期的物料 |
| 替代方案 | 某风险物料更换为候选物料的一套决策（含依据与评分） |
| 本体 | 物料类别层级、属性 schema、兼容约束与替代规则的形式化描述 |
| CBR | Case-Based Reasoning，案例推理 |
| FCE | Fuzzy Comprehensive Evaluation，模糊综合评价 |

## 2 总体描述

### 2.1 用户角色
- **BOM 工程师**：核心用户。导入/维护 BOM、查看风险物料、生成与评估替代方案、应用方案、回溯历史版本。
- **工艺工程师**：查看替代物料性能与工艺兼容性评估，参与方案确认。
- **采购工程师**（扩展）：查看替代物料成本、交期、供应商信息。

### 2.2 运行环境
- 服务端：Python 3.13 + FastAPI + SQLite（无需安装数据库服务）
- 客户端：现代浏览器（Chrome/Edge/Firefox），前端全部库本地化、离线可用
- 部署形态：单机 B/S，`start.bat` 一键启动

## 3 功能需求

### 3.1 业务闭环总流程

```
[FR-1 BOM录入解析] → [FR-2 风险物料识别] → [FR-3 替代物料推理] → [FR-4 方案综合评估]
      → [FR-5 方案保存与历史回溯] → (实际替换效果可回写案例库, 知识闭环)
```

### 3.2 FR-1 BOM 录入与解析
- **FR-1.1 文件导入**：支持 Excel(.xlsx)、CSV、JSON 三种格式；列名支持中英文别名映射
  （物料编码/父件编码/用量/层级/单位/备注）；父件-子件-用量关系解析；层级缺失时按父子关系自动推导；
  未知物料编码自动建档并给出提示；导入结果返回行数与警告列表。
- **FR-1.2 手工录入**：新建产品（含产品工况：温度等级/电压等级/环境）；手工添加 BOM 行（物料远程搜索下拉）。
- **FR-1.3 结构树展示**：多层物料结构树（el-tree），节点显示编码/名称/单台用量/汇总用量
  （自底向上用量之积）/生命周期状态色点。
- **FR-1.4 导入模板**：提供模板文件下载。

### 3.3 FR-2 风险物料识别
- 按风险规则库判定三类风险：
  | 规则 | 类型 | 判定条件 | 级别 |
  |---|---|---|---|
  | R-STK-01 | 缺货 | 库存 < 安全库存 | <50% 高 / 50~80% 中 / 80~100% 低 |
  | R-EOL-01/02 | 停产 | 生命周期 EOL / phaseout | 高 / 中 |
  | R-LT-01 | 交期超期 | 交期 > 阈值(30 天) | >2× 高 / 1.5~2× 中 / 1~1.5× 低 |
- 扫描结果按最高级别排序；每条风险含判定明细（规则 ID、实际值 vs 阈值、解释文案）。
- 风险记录落库，方案应用后自动置为已解决(resolved)。

### 3.4 FR-3 替代物料推理（技术模块 1 + 2）
- **本体知识推理**：对风险物料，经三级过滤输出合规替代集：
  ① 类别约束（同小类，倒排索引检索）；② 参数覆盖（逐属性按 gte/lte/equal 容差/allow_map
  封装升级检查，任一硬属性不满足即剔除）；③ 显式规则（工况规则如"高温工况 X5R 不可替代 X7R"、
  质量底线"故障率不超过原件 3 倍"）与禁止替代对。
  每个候选输出命中规则列表与可读推理路径（trace），前端可折叠展示。
- **CBR 案例推理**：加权 kNN 检索历史变更案例（类别层级相似度 0.30 + 参数相对容差相似度 0.40
  + 工况/原因相似度 0.30，效果加权 success=1.0/partial=0.8/failed=0.5）；
  相似度 ≥0.60 的验证成功案例的替换物料注入候选集（**仍须通过本体硬约束过滤**）；
  相似的历史失败案例以警示卡片展示。
- **候选合并**：本体候选 ∪ CBR 复用物料，去重并标注来源（ontology/cbr/both）。

### 3.5 FR-4 方案综合评估（技术模块 3）
- 五指标：性能匹配度、工艺兼容性（本体软评分：参数裕度与类别属性映射距离）、
  采购成本、供货交期、历史故障率。
- 候选集内 min-max 归一化（成本型/效益型）→ 四级隶属度（优/良/中/差，半梯形+三角形函数，
  论域覆盖完备）→ AHP 判断矩阵（一致性 CR<0.1）+ 熵权法乘法合成权重 → M(·,+) 模糊合成
  → 百分制综合得分与评语等级 → 得分降序（并列成本低者优先）。
- 输出与原件对比（成本变化率/交期差/故障率差）与雷达图。
- 已停产/即将停产的原物料不参与排序（不可再采购），仅作对比基准。

### 3.6 FR-5 方案保存与历史回溯
- 方案保存：方案编号、新旧物料、触发风险类型、证据来源（本体规则命中列表/CBR 案例 ID）、
  FCE 得分与五指标明细落库。
- 方案应用：自动生成新 BOM 版本（快照变更后状态）、更新 BOM 行、关闭该物料 open 风险。
- 版本回溯：BOM 版本时间线、任意版本快照与父版本 diff（新增/移除红绿高亮）、一键回滚
  （回滚本身也生成新版本，历史不丢失）。
- 案例反哺：新案例可手工录入（实际替换效果回写案例库，形成知识闭环）。

### 3.7 FR-6 数据看板
风险类型/级别/状态分布、案例效果分布、FCE 得分分布、本体规则命中 Top5、
累计成本节省、产品/方案/案例统计卡片。

## 4 非功能需求

| 编号 | 需求 | 说明 |
|---|---|---|
| NFR-1 | 轻量离线 | 全部依赖开源；前端库本地化；无外网可运行 |
| NFR-2 | 可解释性 | 风险判定明细、推理路径 trace、FCE 指标明细全程可追溯（答辩可讲解） |
| NFR-3 | 数据可复现 | 仿真数据随机种子固定(seed=42)，seed_all.py 一键重建 |
| NFR-4 | 可测试性 | 算法单测 55 例、e2e 闭环 37 例、前端挂载 16 例，全部自动化 |
| NFR-5 | 架构可扩展 | SQLAlchemy 切 DB_URL 可迁移 PostgreSQL；本体 JSON+规则引擎可替换为标准 OWL+推理机（cypher 可导入 Neo4j） |
| NFR-6 | 过程可审计 | git 全程提交、prompt 会话日志、数据来源如实披露 |

## 6 数据需求与来源（如实披露）

- 物料主数据、产品 BOM、历史变更案例均为 scripts 生成的**仿真数据**（seed=42 可复现），
  非企业真实数据；字段结构与件号体系参考公开数据集与物料分类标准（详见 README「数据说明」）。
- 规模：688 种物料（26 小类/51 类别）、8 个产品（202 行 BOM，3~4 层）、100 条案例。

## 7 验收标准

1. 导入任意合法 BOM 文件（模板格式）成功解析并构建结构树；
2. 对含风险物料的产品扫描，风险类型/级别/明细正确；
3. 替代推理返回合规候选（本体硬约束过滤）与历史案例证据；
4. FCE 对候选排序合理（占优候选得分更高），权重和=1、CR<0.1；
5. 方案保存→应用→版本+1→BOM 行更新→风险关闭→回滚恢复，全链路可验证；
6. 自动化测试全部通过：55 单测 + 37 e2e + 16 挂载。
