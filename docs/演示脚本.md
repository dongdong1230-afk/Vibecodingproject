# 3 分钟演示视频脚本（分镜 + 旁白要点）

**演示主题**：面向离散制造业产品BOM智能解析与物料替代方案推理B/S系统

**录制方式**：双击 `start.bat` 启动系统（或后台运行 `uvicorn app.main:app --port 8000`），
浏览器打开 http://localhost:8000，按下方分镜操作；旁白可现场讲解或后期配音。
建议分辨率 1080P，每个分镜 20~30 秒，总计约 3 分钟。

---

## 分镜 1（0:00-0:25）项目背景与业务闭环

- **画面**：标题页/系统首页（BOM 管理页），顶部业务闭环步骤条高亮。
- **旁白**：本系统面向离散制造企业 BOM 维护痛点：物料停产、缺货、交期过长时，
  人工找替代料效率低、对比维度少。系统实现「BOM 录入解析 → 风险识别 → 替代推理
  → 综合评估 → 方案保存回溯」完整闭环，应用了三个课程技术模块：本体与知识推理、
  案例推理 CBR、模糊综合评价 FCE。

## 分镜 2（0:25-1:00）BOM 导入解析与结构树

- **操作**：BOM 管理页 → 点击「下载导入模板」→「导入 BOM」选择文件 → 展示解析结果；
  在左侧产品列表点击「智能电表 PSM-100」→ 右侧展示多层物料结构树（节点显示用量
  汇总与状态色点）。
- **旁白**：系统支持 Excel/CSV/JSON 导入与手工录入，自动完成层级推导与物料建档，
  构建多层物料结构树，单台用量自底向上自动汇总。演示数据为 8 个典型工业产品的
  3~4 层 BOM。

## 分镜 3（1:00-1:40）风险物料识别

- **操作**：点击「风险识别」→ 选择产品 → 「扫描风险」→ 展示风险物料表
  （缺货/停产/交期超期三种类型红橙黄标签、高中低级别、判定明细展开）。
- **旁白**：按规则库判定缺货、停产、交期超期三类风险，每条风险给出可解释的判定
  明细——规则 ID、实际值与阈值对比。例如这条 EOL 电阻已停产，级别为高。

## 分镜 4（1:40-2:20）替代物料推理（本体推理 + CBR）

- **操作**：点击风险行的「生成替代方案」→ 跳转替代推理页 → 展示中间栏候选卡片
  （逐属性对比 ✓/✗、折叠的推理路径 trace）与 CBR 案例卡（相似度进度条、历史失败
  案例红色警示）。
- **旁白**：这是本体知识推理的输出——同小类候选经参数覆盖与工况规则三级过滤，
  推理路径完整可追溯；右侧是 CBR 检索的历史变更案例，验证有效的替换方案直接复用，
  失败案例给出警示，CBR 推荐的物料同样必须通过本体硬约束过滤。

## 分镜 5（2:20-2:50）FCE 综合评估与方案应用

- **操作**：右侧已选候选 → 「FCE 综合评估」→ 展示得分排序表 + 五指标雷达图 +
  最优方案高亮 → 「保存方案」→ 切到「方案对比」→ 选择方案 → 原/新物料逐项对比
  （成本下降/交期缩短/故障率变化）→ 「应用方案」。
- **旁白**：FCE 对候选做五指标模糊综合评价——AHP 与熵权组合权重、四级隶属度合成，
  百分制排序筛选最优。方案可保存，应用后自动生成新 BOM 版本并关闭对应风险。

## 分镜 6（2:50-3:00）版本回溯与总结

- **操作**：切到「方案历史」→ 展示版本时间线 → 点击版本查看快照与 diff →
  （可选）「回滚」；切到「数据看板」展示统计图表。
- **旁白**：每次变更都有版本快照，支持 diff 对比与一键回滚，历史全程可追溯。
  系统自带 100 余例自动化测试，完整业务闭环可现场演示。

## 答辩要点提示（任务书问答环节）

教师将随机指定 1~2 处 AI 生成的代码段要求现场讲解，建议重点准备：
1. `ontology_service.py` 的 `infer()` —— 三级过滤推理流程与 trace 生成；
2. `cbr_service.py` 的 `retrieve()` —— 三类相似度与效果加权的计算；
3. `fce_service.py` 的 `evaluate()` —— 归一化/隶属度/AHP+熵权/合成排序；
4. `rule_engine.py` —— 无 eval 的 JSON 表达式求值；
5. `substitution_service.py` 的 `apply_plan()` —— 版本快照/行更新/风险关闭的先后顺序
   （本人在开发中踩过"先快照后更新导致 diff 为空"的坑，纠正过程见设计报告 6.3 案例 8）。
